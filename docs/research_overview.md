# 研究の概要

## 背景

機械学習は、物理学でも新しい解析の道具として使われ始めています。その代表例が、統計力学の**相転移**をニューラルネットワークで検出する研究です。

この研究では、相転移の教科書的な例である**2次元イジング模型**を題材に、先行研究3本をPyTorchで再実装して追試しました。そのうえで、次の2つの問いを検討しました。

1. スピン配位だけを見たニューラルネットワークは、相転移を検出できるか
2. 検出できるとすれば、ネットワークは配位から何を読み取っているか

## 2次元イジング模型

$L \times L$ の格子の各点にスピン $\sigma_i = \pm 1$ を置き、エネルギーを次の式で与えます。

$$
H = -J \sum_{\langle i,j \rangle} \sigma_i \sigma_j - h \sum_i \sigma_i
$$

$\langle i,j \rangle$ は隣り合う格子点の組です。周期境界条件を使い、$J = 1$ とします。

- 高温（逆温度 $\beta = 1/T$ が小さい）では、スピンの向きがバラバラになります（**常磁性相**）
- 低温（$\beta$ が大きい）では、スピンの向きがそろいます（**強磁性相**）
- 正方格子の臨界点は厳密に $\beta_c = \frac{1}{2}\ln(1+\sqrt{2}) \approx 0.4407$ です（オンサーガーの厳密解）
- 三角格子では $\beta_c \approx 0.2747$ です

学習用のスピン配位は、マルコフ連鎖モンテカルロ法（熱浴法またはメトロポリス法）で各温度について生成しました。

## 実験1：相の分類器（Carrasquilla & Melko）

→ [experiments/01_carrasquilla_melko](../experiments/01_carrasquilla_melko/)

| 項目 | 設定 |
|---|---|
| データ | 32×32 の正方格子・三角格子。熱浴法で β を 20 点とり、各 90 配位 |
| ラベル | β > βc なら強磁性相、β < βc なら常磁性相（厳密な臨界点を使う） |
| モデル | FCN：1024 → 100 (ReLU) → 2 (sigmoid)<br>CNN：4×4 の畳み込み (stride 4) → 64 → 100 → 2 |
| 学習 | 2値交差エントロピー、Adam (lr = 1e-3)、20 エポック。訓練データと検証データは半分ずつ |

**結果**：出力の確率は、厳密な臨界点の前後で 0 と 1 が入れ替わりました。正方格子で学習したモデルに三角格子の配位を入力しても、三角格子の臨界点で出力が入れ替わりました。モデルは格子の形によらない特徴（スピンのそろい具合）を学習していると考えられます。

**限界**：学習に臨界温度の情報（ラベル）が必要なため、臨界点が未知の系にはそのまま使えません。

## 実験2：温度測定器（Tanaka & Tomiya）

→ [experiments/02_tanaka_tomiya](../experiments/02_tanaka_tomiya/)

| 項目 | 設定 |
|---|---|
| データ | 8×8 と 16×16。メトロポリス法で β = 0.2〜1.0 を 100 等分し、各 100 配位 |
| ラベル | 配位の温度（100 クラスの one-hot）。**相転移の情報は与えない** |
| モデル | FCN：L² → 80 (ReLU) → 100<br>CNN：周期境界パディング + 3×3 畳み込み (5 ch, stride 2) → 100 |
| 学習 | 交差エントロピー、Adam (lr = 1e-3)、左右・上下反転によるデータ拡張 |

**解析**：最後の全結合層の重みを温度ラベルごとに足し合わせ（$W_{\rm sum}$）、温度に対してプロットします。$W_{\rm sum}$ は臨界点の付近で急に変化するので、tanh 関数でフィットし、その中心から臨界温度を推定しました。

**結果**：FCN と CNN のどちらでも、おおよその臨界温度を検出できました。格子サイズが大きいほど推定の精度が上がる傾向がありました。モデルの違いによる精度の差はほとんどありませんでした。

## 実験3：ネットワークは何を学んでいるか（Kashiwa, Kikuchi & Tomiya）

→ [experiments/03_kashiwa_kikuchi_tomiya](../experiments/03_kashiwa_kikuchi_tomiya/)

| 項目 | 設定 |
|---|---|
| データ | 16×16。メトロポリス法で β = 0.05〜1.0 を 20 等分し、各 2000 配位 |
| モデル | FCN：256 → **3** (softmax) → 20<br>CNN：畳み込み 3 層 (64 → 32 → 3 ch) → 20 |
| 学習 | 交差エントロピー、Adam (lr = 3e-3)、100 エポック |

隠れ層を 3 ユニットまで絞ると、各ユニットが何に反応しているかを直接調べられます。

**結果**

- **FCN** の第1層は、配位の**磁化**（スピンの平均）をとらえていました。第2層の重みは臨界点で急に変化し、これが相転移の検出につながります。
- **CNN** は磁化ではなく、配位の**内部エネルギー**（隣り合うスピンの相関）をとらえていました。最後の層の重みは急に変化せず、オンサーガーの厳密解から得られる自由エネルギーを使った理論曲線とよく一致しました（厳密解の数値計算は `onsager.ipynb`）。
- 温度を当てる精度は CNN の方が高い一方、相転移は磁化をとらえる FCN の方が見つけやすい、という対照的な結果になりました。どの物理量を抽出するかは、ネットワークの構造と学習の仕方で変わります。

## まとめ

- 単純なニューラルネットワークでも、2次元イジング模型の相転移は検出できます。
- 温度測定器を使えば、臨界温度を教えなくても、学習済みの重みから相転移を見つけられます。
- 学習済みネットワークの内部を見ると、磁化や内部エネルギーといった物理量に対応する特徴が現れます。機械学習のモデルを「物理量を抽出する道具」として解釈できることを確かめました。
